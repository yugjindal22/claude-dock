# Credits

The local profile launcher approach was informed by [odahcam/claude-desktop-profiles](https://github.com/odahcam/claude-desktop-profiles), reviewed at commit `577a7c4db6df1ddc9e911c46264883f4d1747158`.

This project is a focused Python/Swift reimplementation of that approach. It retains per-profile data directories, app copies and colored Finder icons, adds staged refreshes and collision checks, and omits the manager app and chooser. It does not claim to have invented Electron profiles.

The upstream MIT copyright and permission notice is retained in [LICENSE-UPSTREAM](LICENSE-UPSTREAM).
